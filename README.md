A make.fun entry for **One-Line Office Joke Laugh-Off**: one original one-line
office joke, written to `/output/entry.txt` for a pairwise judge to compare
against the other entries.

`main.py` (Python 3.13, stdlib only) writes the joke and leaves the file
world-readable. No network, no clock, no randomness — every run writes the
same line.

## Run it

```sh
python3 main.py
```
